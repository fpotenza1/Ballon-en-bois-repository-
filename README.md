# Ballon en Bois — Minimal Edition

Static website for Vercel. Homepage, nominees, rankings and methodology are navigable through hash routes.

## Deploy
Upload `index.html` and `vercel.json` to the root of the existing GitHub repository. Vercel should redeploy automatically when committed to the connected production branch. Framework preset: Other; no build command.

## Editorial notice
All player names, club names and index scores are fictional placeholders. Replace the `players` array with independently researched, attributed nominations before publication. No backend voting is included.
